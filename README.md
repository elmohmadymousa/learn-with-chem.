# مختبر الكيمياء — تعلم باللعب

مشروع لعبة تعليمية عربية تفاعلية تهدف إلى تعليم أساسيات الكيمياء من خلال تجارب بسيطة وواجهة سهلة الاستخدام.

## ما الذي تم تطويره
- واجهة عربية كاملة من اليمين إلى اليسار.
- نظام تحديات تعليمية (اصنع الماء، الملح، ثاني أكسيد الكربون، أكسيد النحاس).
- اختيار عناصر مختبرية وتفاعلها في وعاء التجربة.
- نظام نقاط وسلسلة إنجاز.
- أسئلة سريعة للتقييم الفوري.
- تصميم متجاوب مناسب للحاسوب والهواتف.

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## ملاحظات
- المشروع محاكاة تعليمية وليست تجربة كيميائية حقيقية.
- مناسب كأداة تعليمية تفاعلية في الصف أو للتمارين المنزلية.

## الخطوة القادمة
يمكن تطوير المشروع لاحقاً لإضافة:
- أصوات ومؤثرات تفاعلية
- مستويات أكثر تعقيداً
- قائمة سجلات الإنجاز
- نظام ترتيب نقاط
- شاشة بداية ونهاية اللعبة
